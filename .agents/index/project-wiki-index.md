# Project Wiki Index

**Scope:** `wiki/`, except `wiki/logs/`
**Parent:** [Root Index](root-index.md)

Pages here are plain markdown with no frontmatter, written for a person maintaining
this repository. They describe **the repository**, not the jwz package — the package
is documented on the published site under `docs/`, and facts about it belong there
and in the `jwz` repository. Release history lives in
[`logs-index.md`](logs-index.md); knowledge written for agents lives in
[`agent-wiki-index.md`](agent-wiki-index.md).

Any page added to or removed from `wiki/` is reflected here in the same commit.
