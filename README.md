# jwz-website

## Overview

This repository holds the documentation website for the [jwz](https://github.com/JetsadaWijit/jwz) package. It is a static site, published with GitHub Pages, that documents every module jwz provides: the Git platform utilities for GitHub and GitLab, the AI provider clients for DeepSeek, OpenAI, and OpenRouter, and the Outlook mailer.

The pages under `docs/` contain the rendered documentation and runnable code examples.

## Full Documentation

This page is only a short overview. To understand the project fully, browse the live website:
